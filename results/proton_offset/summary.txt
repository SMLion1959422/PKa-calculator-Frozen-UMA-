== TEST 1 (internal): does the offset transfer across chemical families? ==
weighted mean over 24 (solvent, family) cells, n=1238:
  offset fitted on OTHER families   MAE 1.65
  offset fitted on the family itself 0.97   (cheating lower bound)
  no shift at all                    7.12
-> the offset captures 89% of the achievable improvement without seeing the
   target family: (7.12-1.65)/(7.12-0.97). It is largely, not purely, a
   solvent property. Worst cells: MeCN C-H acids (4.92), DMSO other O-H (3.71),

  all 6 with a literature value: slope 0.77  intercept +7.41  r2 0.603
  EXCLUDING acetonitrile:        slope -0.11 intercept +5.62  r2 0.088   <-- no correlation
  verified values only (n=3):    slope 0.97  intercept +7.21  r2 0.741

== decomposition of the residual (offset - proton term) ==
The residual splits cleanly by the solvent's H-bond DONOR ability:
  protic  (alpha>0.5): MeOH +3.44, EtOH +3.84            mean +3.64
  aprotic (alpha<0.5): MeCN +8.62, NMP +8.19, DMSO +9.39, DMF +10.68  mean +9.22

residual vs d_alpha = alpha(S) - alpha(water), n=5 (NMP dropped, n=17):
  slope -6.90  intercept +1.92  r2 0.979  max residual 0.68
  vs beta (H-bond ACCEPTOR): r2 0.032  <-- specificity check: no relation
  linear in alpha    : in-sample maxresid 0.68, LOO MAE 0.60
  binary protic/aprotic:                  1.11,          0.83
  constant only      :                    3.76,          3.55

two-term model, n=5 solvents, 3 parameters:
  offset = +0.99*dG_tr(H+)[pK]  -6.87*d_alpha  +1.96
  in-sample residuals: MeCN +0.01, DMF +0.65, DMSO -0.63, EtOH -0.22, MeOH +0.19
  LEAVE-ONE-SOLVENT-OUT MAE 1.14 (MeCN 2.28, DMF 1.29, DMSO 1.28, EtOH 0.39, MeOH 0.46)

  The coefficient on the proton term is 0.99, i.e. 1.00 within error, which is
  what the thermodynamic cycle requires. The second term is the mean anion
  transfer free energy: an anion is an H-bond ACCEPTOR, so what matters is the
  solvent's ability to DONATE H-bonds (alpha), and beta is correctly irrelevant.

== limitations ==
* 5 solvents, 3 parameters. Using only VERIFIED literature values leaves 3
  points for 3 parameters, i.e. zero degrees of freedom: the fit's testability
  currently depends on the DMF and ethanol values that are flagged UNVERIFIED.
  Re-deriving those from a primary compilation is a prerequisite for publishing.
* Sensitivity: perturbing the unverified values by +-1 kcal/mol moves the alpha
  slope over [-7.91, -5.93], so the sign and rough size are robust to that,
  but the exact coefficient is not.
* alpha beats a binary protic/aprotic split, but only MeCN (alpha 0.19) lies
  between the two clusters, so the linear form is weakly determined.
* The three aprotic solvents span 8.19-10.68 with essentially no alpha variation;
  that 2.5-unit spread is unexplained.
* NMP (n=17) and ethylene glycol (n=18) are too thin to use.
* The offset is a MEDIAN over this dataset's chemistry; the per-molecule spread
  (IQR 0.6-3.0) is the part no per-solvent constant can capture.

== CORRECTION / AUDIT (added after review) ==
UNITS. offset is median(pKa_S - pKa_W), in pK units. pk_units() converts the
literature dG_tr(H+) from kcal/mol to pK units by dividing by 1.3637. BOTH
sides of the regression are therefore in pK units and the cycle mandates a
coefficient of 1.00. (Had the literature term been left in kcal/mol the
mandated value would be 1/1.3637 = 0.733. It was not.) Units check out.

JOINT vs SEQUENTIAL. The 0.99 coefficient DID come from a joint least-squares
fit of offset on [dG_tr(H+), d_alpha, 1], so it was not pinned by construction.
BUT the write-up quoted "r2 0.979" beside it, and that number comes from the
SEQUENTIAL analysis (residual = offset - lit, then regressed on d_alpha), where
the H+ coefficient IS pinned to 1. Quoting them together conflated two
analyses. They are now reported separately.

CONFIDENCE INTERVALS (joint fit, n=5, 3 parameters, residual dof=2):
  dG_tr(H+)   +0.990  SE 0.077  95% CI [+0.658, +1.322]
  d_alpha     -6.870  SE 0.744  95% CI [-10.073, -3.667]
  intercept   +1.956  SE 0.668  95% CI [ -0.916,  +4.828]
The CI on the proton coefficient does NOT exclude 0.733, or much else.
Freeing that coefficient reduces RSS from 0.920 to 0.913 - the data barely
constrain it, and 1.0 fits essentially as well as 0.99. So "1.00, exactly as
the cycle requires" is TECHNICALLY TRUE AND EVIDENTIALLY WEAK. The honest
statement is that the fitted value is consistent with the mandated 1.00, not
that it confirms it.

ALPHA vs BINARY. LOO 0.60 (linear in alpha) against 0.83 (binary
protic/aprotic) on five points is not a distinguishable difference, and the
only solvent making alpha continuous rather than two-valued is acetonitrile
(alpha 0.19) - the same high-leverage point that produced the spurious r2 0.60
in test 2. The data cannot distinguish a continuous alpha dependence from a
two-state protic/aprotic one. The two-term decomposition survives either way.

== UPDATE: literature values re-sourced, DMF corrected ==
TATB-assumption recommended values located in the secondary literature
(kJ/mol): MeOH 8.7, EtOH 11.1, MeCN 44.8, DMSO -19.4, DMF -14.4.

Four of the five independently REPRODUCE the values already in the table
(to <= 0.05 kcal/mol), including the three previously marked verified.
DMF did not: the earlier UNVERIFIED entry used -18.4 kJ/mol, and the
sourced value is -14.4 kJ/mol -- wrong by 0.96 kcal/mol = 0.70 pK units.
Ethanol's guess (+2.6 kcal) was very close to the sourced +2.65.
No value was located for NMP or ethylene glycol; both are left out (and
both have <20 paired rows anyway).

Rerunning the decomposition with the corrected DMF value:

                        BEFORE (bad DMF)      AFTER (corrected)
  joint dG_tr(H+) coef  +0.990                +1.019
  its 95% CI            [+0.658, +1.322]      [+0.841, +1.196]
  d_alpha coef          -6.870                -6.657
  LOO MAE               1.14                  0.40
  aprotic spread         2.06                  1.36
  sequential r2 (alpha)  0.979                 0.993
  specificity: r2 (beta) 0.032                 0.041

Two things follow.

1. The CI on the proton coefficient now EXCLUDES 0.733 (the value that
   would be mandated if the two terms were in mismatched units) while
   containing the 1.00 the cycle requires with matched units. Before the
   correction the CI contained both and discriminated nothing. This is
   now an actual passed test rather than a vacuous one.

2. Roughly a third of the previously "unexplained" aprotic spread
   (2.06 -> 1.36 pK) was a bad literature input, not chemistry.

Note what did NOT cause the improvement: no parameter was added and no
fit was freed. A single input was replaced with an independently sourced
value, and the residuals fell. That is the behaviour of a correct model
given a corrected input.

STILL OUTSTANDING: none of these five values has been read by this
project off a PRIMARY table; they are secondary reports of the TATB
compilations, cross-checked against each other. Methanol alone is quoted
at both 8.7 and 10.4 kJ/mol by different compilations (0.4 kcal spread),
which bounds the achievable accuracy. Read them from a primary source and
cite it before publishing.
